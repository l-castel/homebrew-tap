# Copland

A terminal-styled client for [Navidrome](https://www.navidrome.org) music servers, for iPhone and Mac.

Copland plays music from your own Navidrome (or other Subsonic-compatible) server: browse albums, artists and
playlists, search, build and edit playlists, and save albums for offline listening. You need a server of your own
to use it; Copland doesn't come with any music.

## Support

Questions, bugs and feature requests: [open an issue](https://github.com/l-castel/homebrew-tap/issues/new?title=Copland:%20)
on GitHub.

**Can't sign in?** Enter your server's address as you'd open it in a browser (for example
`https://music.example.com` or `http://192.168.1.20:4533`), with your Navidrome username and password. To try the
app without a server, use Navidrome's public demo: `https://demo.navidrome.org`, user `demo`, password `demo`.

**Mac:** `brew install --cask l-castel/tap/copland`
